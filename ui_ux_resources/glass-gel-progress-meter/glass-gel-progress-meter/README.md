# Glass/Gel <progress> meter

A Pen created on CodePen.

Original URL: [https://codepen.io/simeydotme/pen/bNEaqmb](https://codepen.io/simeydotme/pen/bNEaqmb).

Using some of the styling from the Gel/Glass slider, and some styling from the Iridescent Button, I wanted to try applying a beautiful style to the default <progress> element. 

This is fairly restrictive; no transitions, cross-browser differences, no ::before/::after but I think I got pretty close with shadows/gradients!
